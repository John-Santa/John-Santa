# Hola, soy John Santa 👋

Soy un **Backend Engineer** enfocado en solucíon de problemas complejos mediante código limpio y mantenible haciendo uso de **patrones de diseño**. Actualmente estoy expandiendo mis conocimientos hacia la **arquitectura de software y DevOps** para construir y desplegar sistemas altamente escalables.

### 👨‍💻 Sobre mí
* 🚀 Previamente, me desempeñé como Software Engineer en **Mercado Libre**.
* 🏗️ Tengo un fuerte dominio estructurando el lado del servidor y resolviendo problemas complejos a través de patrones de diseño.
* 🌱 Actualmente enfocando mi aprendizaje en el diseño de arquitecturas orientadas a microservicios, integración/entrega continua (CI/CD) y orquestación de contenedores.

### 🛠️ Tecnologías y Herramientas
* **Lenguajes & Frameworks:** Java, Go, Spring Boot, Quarkus.
* **APIs & Arquitectura Base:** Patrones de Diseño, REST, OpenAPI.
* **Bases de Datos & Caché:** PostgreSQL, MySQL, MongoDB.
* **DevOps & Infraestructura (En aprendizaje continuo):** Docker, Kubernetes, Jenkins, Prometheus, Grafana.

### 🔭 Proyectos Destacados
* **TableX:** Desarrollo de una aplicación con integración funcional completa entre el frontend y múltiples conexiones en el backend.
* **Clasificador de Enlaces (Telegram):** Herramienta automatizada para capturar, procesar y categorizar links de redes sociales (Facebook, Instagram, TikTok) compartidos vía Telegram, organizándolos dinámicamente por área y ubicación geográfica.
